# StatIntel Competency Framework Specification

Aligned with MoSPI cadre standards and the SIH26101 Problem Statement, the framework structures 33 official competencies across 4 foundational domains:

## 1. Statistical Domain (10 Competencies)
| Code | Competency Name | Benchmark | Weight | Description |
| :--- | :--- | :---: | :---: | :--- |
| `STAT_SURV` | Survey Design | 80 | 1.0 | Survey questionnaires, pilot tests, frame creation |
| `STAT_SAMP` | Sampling | 85 | 1.2 | Multi-stage stratified sampling, PPS, design weights |
| `STAT_NACC` | National Accounts | 75 | 1.0 | GDP compilation, GVA, supply-use tables, SNA standards |
| `STAT_PRIC` | Price Statistics | 75 | 0.9 | CPI/WPI calculation, index weighting, deflation |
| `STAT_LABR` | Labour Statistics | 75 | 0.9 | PLFS methodology, LFPR, WPR, activity status |
| `STAT_AGRI` | Agricultural Statistics | 70 | 0.8 | Crop estimation surveys, agricultural census |
| `STAT_INDU` | Industrial Statistics | 70 | 0.8 | ASI schedules, IIP calculations, NIC codes |
| `STAT_SDGS` | SDG Indicators | 80 | 1.0 | National Indicator Framework (NIF) tracking |
| `STAT_META` | Metadata Standards | 75 | 0.9 | SDMX, DDI schemas, statistical catalogue harmonization |
| `STAT_QUAL` | Data Quality | 85 | 1.1 | NQAF framework, validation, non-sampling error control |
